# Chinmaya Chikitsalaya — Prayagraj | Healthcare & Seva Platform

A complete, premium, production-quality frontend website for **Chinmaya Chikitsalaya — Prayagraj**, combining Healthcare, Compassion, Seva, Trust, and Community Impact.

## 🚀 Live Demo & Deployment

* **Local Dev Server**: `npm run dev` (`http://127.0.0.1:5173/`)
* **Production Build**: `npm run build`
* **GitHub Pages Deployment**:
  1. Add remote repository: `git remote add origin https://github.com/YOUR_USERNAME/chinmaya-chikitsalaya.git`
  2. Push code: `git push -u origin main`
  3. Deploy to GitHub Pages: `npm run deploy`

## 🛠️ Built With

* **React 19** + **Vite 8**
* **Tailwind CSS v4** (`@tailwindcss/vite`)
* **Lucide Icons**
* **Google Fonts**: `Playfair Display`, `DM Serif Display`, `Plus Jakarta Sans`

## 📜 Key Sections

- **Hero & Trust Strip**: Cinematic hero with warm saffron overlay and trust points.
- **Quick Action Tiles**: Appointment booking, doctor search, directions, and OPD contact.
- **Services & Doctor Directory**: Filterable OPD services & doctor cards with scheduling modal.
- **5-Step Appointment Scheduler**: Step 1-5 flow with confirmation ID generation, downloadable receipt, and `.ics` calendar file.
- **Impact & Community Seva**: Statistical counters, featured free medical camp spotlight, and rural outreach gallery.
- **Health & Wellness Hub**: Patient education articles with category pills and modal reader.
- **Gallery Lightbox**: Category tabs (`Hospital`, `Doctors`, `Community`, `Camps`, `Events`) with fullscreen Lightbox.
- **Support / Donate & Volunteer**: Donation presets (₹100, ₹500, ₹1000, ₹5000, Custom) with prototype demo receipt preview + volunteer application form.
- **Transparency & Governance**: Public compliance PDF previews.
- **Location & Contact**: Prayagraj address, OPD hours, map visualizer, and contact form.
